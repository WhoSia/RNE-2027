# R&D evidence gate — proposed teacher-approved tabletop protocol (not executed)

Purpose: test whether measured information changes a constrained laboratory decision; not demonstrate an actual traffic controller. Use only abstract paper tokens on a classroom table and a printed ledger. No public road activity, personal tracking, wireless measurement, or camera required. Teacher approval and students' independent work are required before any empirical claim.

Two lanes, two pocket spaces each, four shared-queue tokens with binary movement labels; stage service and arrival events are written on sealed event cards before a paired replay. A teacher/student environment operator follows the model transition, sees true token order and records the state privately. The policy operator receives only the allowed count/measurement message, never the hidden order or future cards. Identical initial word and event cards are used for all compared policy replays; balance replay order so that the first replay does not reveal the next policy's hidden information. Prefer independent observers or independently generated blinded sessions if operators cannot avoid remembering the prior order. Use fixed IDs and separate observation and truth logs; record missing/ambiguous values as such, not zero.

Frozen primary comparison: R2 exact adaptive vs class-informed optimal fixed calendar under budget 4 for the two previously defined objectives. Select the calendar using the synthetic model BEFORE collecting evidence, not from actual test outcomes. Distinguish a deterministic algorithm/transition reproduction trial (perfect token visibility to environment operator) from a measurement-reliability trial (observer reads the authorized partial display; independently compare with truth). Record pre-arrival residuals S/L, stage maximum, terminal residual, actual acquisition credits, protocol deviations and unsupported observations. Any wrong model transition is a protocol discrepancy, not a sensor error; retain all deviations. Do not combine these with field data.

Planning sample: 4 known initial classes ×4 balanced permutations/event streams =16 paired blocks as a feasibility pilot, not a powered statistical sample. Freeze actual cards, operator assignments, observation rules and exclusion criteria before testing, preferably through a teacher-reviewed worksheet. Use separate pilot and subsequent validation batches if estimating a confusion matrix. Do not discard difficult blocks or count repeated stage observations as independent. Report paired differences with uncertainty only if sample size/design supports it. If no independently confirmed advantage, retain that finding. The 16-block proposal is not an executed student experiment or a statistical power calculation.

Schema: block_id, law, initial_class, hidden_word (truth-only), stage, policy_id, allowed_measurement, observed_value, true_value (truth-only), acquisition_cost, remaining_budget, action, residual_S, residual_L, next_observation, error_or_missing, protocol_deviation. Keep separate predecision observation logs and sealed ground-truth logs until scoring. Do not enter student names or personal information in shared data. Teacher and students decide whether to execute and how to document their own contributions.
