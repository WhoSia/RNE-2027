## Exact methodological harvest and adversarial loop

- **Reviewer claim**: state which T2/RF requirement is alleged violated and where it is defined. A reviewer merely saying "bad sensor model" is not enough.
- **Independent test oracle**: exact synthetic observation maps and locked model assertions for math; measured, authorized physical sensor data for CSI; real controller feasibility specifications for admissible traffic signals. A simulated signal's mathematical success does not pass a field acceptance test.
- **Proposed correction**: freeze before/after implementation, run the SAME external oracle; report false-positive reviewer objections as well as true faults. Do not optimize only to agree with a Claude or ChatGPT critique.
- **Refinement boundary**: 2-bit ideal abstract sensor -> software observation feature -> measured radio trace -> urban road vehicle state -> lawful controller action is a **sequence of hypotheses and evidence requirements**, not a single function proven correct by unit tests.
- **Completion boundary**: paper PDF moved to 10_PAPERS means storage complete; reading abstract means first reading only; 11 local tests means toy code property exercised; external CSI field classification and T2 physical transport both remain OPEN.
