# RF08 — Independent exhibition acceptance for T2 simulator and RF sensor

Keep two exhibit deliverables instead of forcing one fragile integrated gadget.

## A. T2 physical-model exhibition (software only)
- Interactive demonstration: demand arrival timing, pocket geometry, downstream finite storage and effect on queue/delay.
- Before claiming a 'good signal', run abstract timing P12 validator and show 'not physically/controller validated' where applicable.
- Show matched-state policy branch under equal predecision microstate, then one independently varied clock world.
- Explain non-identical observations versus same-observation causal ambiguities using P13 screening.
- Validate vehicle count conservation, checkpoint reproducibility, and output provenance.

## B. CSI/multimodal exhibition (optional apparatus)
- Show actual measured subcarrier amplitudes or a cheaper independently measured channel only if approved gear exists.
- Contrast empty, moving and stationary states. Label uncertainty, repeated sessions, false positives, sensor placement.
- Visually separate the real sensor trace, modelled classification and independent truth labels.
- No literal 'Wi-Fi image' unless geometric localization has its own independent evaluation; do not re-render fake person images from RF numbers.

## Joint integration is a bonus, not a gate
Only measured error/confusion from B may be introduced into T2's decision-value evaluation. Simulated CSI features are engineering fixture, not empirical detection rates.

## Stop/accept criteria
A and B each need their own independent baseline, negative outcomes and demonstration artifact. The T2 branch is meaningful even if CSI fails; the CSI experiment remains independently publishable as an honestly bounded hardware study even if T2 calibration is incomplete.

No live road signal changes, no unauthorized RF observations, K047 holdout sealed, CIM large dataset untouched.
