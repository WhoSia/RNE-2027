## Direct implementation

`t2_p16_checkpoint_contract.py` checks the six integer occupancies and four occupied-cell lists for shape, consistency, duplicate cells, and downstream index bounds. It exposes only safe computational proxies:

- `pocket_present`: simulator pocket count is nonzero.
- `receiver_full`: number of receiver vehicles equals declared capacity.
- `receiver_entry_cell_occupied`: downstream stopline-adjacent cell index 0 occupied, **distinct from** link fullness.
- `receiver_free_cells`: remaining finite storage.
- `coarse_proxy`: pair of booleans (pocket present, receiver full).

Crucially, `rf_five_class_label` stays `None` and status is `UNIDENTIFIABLE_FROM_SINGLE_CHECKPOINT`. A single simulator snapshot cannot label `free` as traversing traffic, `no_demand` as absence of arriving demand, or a staged `pocket` object as the cause of a blocked turn. It also cannot infer measured Wi-Fi CSI.

`audit_phys04_pairs(rows)` accepts **existing genuine PHYS-04 formatted records only** and can screen equal six counts with identical capacity, pocket geometry and B share for opposite signs beyond a chosen model-unit epsilon. It DOES NOT infer any RF cause class, and it does not claim independent traffic-day replications from distinct seed strings. It does not run the engine; user must supply actual outputs generated by the canonical PHYS runner.

## Still-open scientific gates

1. **Time and stationarity:** Determine whether a pocket vehicle is static/stationary and *why* it cannot enter using temporal `trace` or `access_events`, not a single count. Unlike PHYS's vehicle IDs, RF ground-truth labels are manually staged external conditions, requiring a validation design before any mapping.
2. **Signal action contract:** PHYS-04 phase intervention uses abstract lights `L/S/-` and an invented time window. P12 covers only invented minimum timings, not real green/yellow/red/pedestrian rights; linking is NOT a safety certification.
3. **Uncertainty:** Even if a six-count alias appears, distinct cases may have different future arrival requests and route sequences; do not claim deterministic prediction impossibility without specifying what was observable at decision time and which future distributions were conditioned upon.
4. **Independent samples:** PHYS-04 seeds may share deterministic timestamp patterns under uniform demand. A seed count alone cannot be treated as independent arrival-clock sample size.
5. **Nonzero link capacity:** P16 deliberately rejects zero-capacity/non-cell modes for its downstream-cell semantics; broader engine states need a separately declared adapter.
6. **Exact output provenance:** A valid future PHYS-04 JSON run should include source git tree SHA, runnable command, record count, frozen action definition, and output SHA-256.
7. **Negative results:** If no strict opposite signs occur under truly identical decision-time observation and action contract, report **NO_WITNESS**, not artificially broaden the label.

## Logic correction (same day)
For a link with N cells and one vehicle per distinct occupied cell, full occupancy (N vehicles) **implies cell 0 is occupied**. The converse is false: cell 0 can be occupied while the remaining N−1 cells are empty. The initial adapter docstring accidentally reversed the first implication. It was corrected without changing the functional predicate, and a new regression over capacities 1/2/3/4 brought the exact-byte-tested suite to **20/20**. This is a documentation/model-logic correction, not an RF physics observation. Final test source SHA-256 `036b44d28bc6f787f3a7d8e3416f1fffabe47b7ca00798ec72d7094fb34c2bac`.
