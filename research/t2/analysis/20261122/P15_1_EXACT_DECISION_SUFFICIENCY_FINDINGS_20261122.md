# P15-1 — RF class-to-T2 decision sufficiency: exact fixture findings

Date 2026-11-22 KST. This is a **software/mathematical validation of the pre-existing P15 interface contract**. It is NOT an RF recording, a re-run of the PHYS traffic engine, a same-observation PHYS witness, or an operational signal plan.

## Research question
Does a staged five-class RF label (no_demand/free/pocket/downstream/both) contain enough information to select a common optimal action among several **hypothetical** worlds with different pocket occupancies and downstream storage?

For a finite compatibility set W(z,c,A), where z is a manually assigned tabletop label, c is an explicitly named abstract action contract, and A is the same available action set for every world:
- **Common-action decision sufficiency:** intersection over x in W of argmin_a J(a,x) is nonempty.
- **Minimax regret:** min_a max_x [J(a,x) - min_b J(b,x)].
- **Two-action strict-sign screen:** for delta(x)=J(treatment,x)-J(baseline,x), require some delta < -epsilon and another > epsilon; epsilon=5 artificial cost units in fixtures.
- **State aliasing:** distinct values of the two *displayed* toy features (pocket_vehicles, downstream_free_cells) exist inside a common label. This does not guarantee a physically realizable RF label or exhaust a T2 microstate.
- **Cohort validity:** never pool separate artificial thought experiments, dissimilar actions or contracts. Distinct arrival_group strings are *declared grouping metadata*, NOT verification of independent traffic histories.

## Fixture results (exact Fraction, no statistical fitting)

| Cohort | Label | States (pocket vehicles, downstream free cells) | delta treatment - baseline | Common optimum | Minimax regret |
|---|---|---|---|---|---|
| OPPOSITION | pocket | (1,3); (4,1) | -8; +9 | none | 8 (baseline robust) |
| COMMON | pocket | (1,3); (4,1) | -3; -1 | treatment | 0 |
| TIE | both | (1,0); (4,0) | 0; +2 | baseline | 0 |

OPPOSITION exhibits a strict sign-opposition pair (o1,o2) and no universally optimal action under the **invented cost table**. The regret of baseline in o1 is 8 and in o2 is 0, whereas treatment's regrets are 0 and 9; thus the minimax choice is baseline with worst-case regret 8. These numbers were *chosen* to demonstrate the mathematical condition, not obtained from physical or empirical traffic.

COMMON is an essential **negative control against overclaiming**: the same coarse RF label collapses two different displayed state vectors, yet treatment is optimal in both. Therefore label non-injectivity alone does NOT entail a decision problem.

TIE verifies that a weakly common optimal action can exist even when preferences are not identical in all worlds. Do not misreport a nonzero treatment cost in one world as strict opposite-sign evidence.

If both opposing records share the same declared arrival_group, the scanner now reports them as same_arrival_group_pairs rather than independent cross-group witnesses, preventing silent pseudoreplication. It cannot verify the actual origin or randomness of groups.

## Scientific and implementation limitations

1. **Chosen costs** make the strict opposition example tautological; the result is a correct checker, not a discovered causal mechanism. The independent review must assess whether we are proving only our fixtures, and whether the scanner can ever be fed genuine, feasible PHYS states.
2. **No probability prior** exists for the worlds, so this calculation is minimax regret rather than Bayes expected sensor value (unlike RF06/RF07 toy).
3. **RF labels are staged experimental labels**, not measured CSI. The map h(x) from detailed PHYS state to tabletop class has not been validated. Wireless measurements might depend strongly on within-class object placement or material.
4. **Feasibility is only matched as a string/action set**. We did not invoke P12 nor verify Korean legal signal plans. A fake contract name can pass the data shape.
5. **Distinct arrival_group identifiers are only assertions in fixture metadata**; no code proves independence, and exhaustive enumeration is not field sampling.
6. **Compatibility set completeness:** the audit tests only enumerated worlds. A common optimum on two fixtures never establishes sufficiency for all physically possible traffic states.
7. **Strict epsilon** qualifies the sign-witness reporting but does not define epsilon-optimal actions. The exact-optimal intersection is intentionally more stringent; both must be reported separately.
