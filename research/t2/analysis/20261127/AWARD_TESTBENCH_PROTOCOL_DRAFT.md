## Distinguish the two studies
A: P87/P135 network simulation policy study (30 vs 60-second period). Reproduce and transfer to fresh prerecorded synthetic arrival tapes/topologies, evaluate objective differences. Do NOT map 30/60 seconds to the R3 abstract three-stage model.
B: Existing R3 tabletop token testbench, independent manual reference. Three stages; upper pocket and FIFO counts are free, paid head/full word/downstream vector abstract credits 1/4/1. Receiving and service are model parameters. Test whether actual independently recorded occupancy labels and observation errors support policy decisions and information value. All 80 R3 contexts tied the best class-informed fixed calendar, so no adaptive-schedule superiority claim. Treat it as a serious negative benchmark, not a missing feature.

## B: minimum pilot before confirmatory trial
Pilot suggestion: 12 resettable scenarios; distinct randomized token arrangement cards, arrival cards and service cards frozen before opening. Balanced inclusion of no receiving block, receiving block and near-capacity states; actual group sizes selected by teacher after reviewing feasibility. A student operating the model sees only declared observations, not hidden truth. Another student records actual tokens and timestamps using the cards and manual count, records before seeing policy result. Swap roles across pilot blocks. Use simple paper tokens and paper/CSV records, no real roads, no hardware needed. Re-run exact tape for different observation schedules from identical initial arrangement; randomize run order within block, restore all tokens and verify ID counts before next arm. Note that randomized cards and reset do not guarantee student independence; log session and observer labels, potential learning/order effects. Separate calibration and evaluation blocks by tape AND session when feasible; no reuse of pilot to claim held-out performance. Do not select best fixed calendar using test outcomes: fit only calibration, lock and compare class-informed fixed calendar(s) and equal-budget candidate. Match budget ceiling and record actual spent credit separately. Full state is oracle reference, not a fair acquisition budget comparator.
Primary proposal: paired whole-system token-stage cost difference with same horizon and terminal accounting under frozen equal-budget candidate vs predetermined fixed schedule. Secondary: channel disagreement versus independent label, worst-case and per-stratum regret, actual credits, time to result, invalid/missing/abstain, inter-observer agreement, conservation identities. If candidate ties baseline, report no gain, and evaluate whether cost/simplicity justify retaining it. Never condition benefit on only completed/successful observations. Record failures separately; define fallback/penalty before validation (teacher review needed). No fabricated missing observations. R3 model prior does not establish physical sensor accuracy; paper test verifies algorithm and observer protocol only.
## Statistical gate
Use pilot variance and meaningful practical effect to select continuous endpoint sample size; if sign-test secondary is desired, exact 40 independent non-tied blocks gives power .807 at assumed win probability .70, only .572 at .65; 50 attempted gives 40 in expectation if 20% ties, no guarantee. Ties disclosed. Session clustering, repeated stage/observation rows, shared tape arms not independent. Preselect primary endpoint and comparator; analysis locked before held-out collection, report mean and median paired difference with block-level uncertainty and individual differences. Holm for multiple confirmatory secondary hypotheses or designate exploratory. Stop only for predeclared sample/budget or safety/feasibility, never for convenient p-value. Student writes hypotheses, operates, records failures, interprets evidence and documents AI assistance according to school rules. 
## Pass / revise
Pilot passes only if every block resets, teacher/student can reproduce ledger without model author, independent labels time-aligned, no duplicate block IDs or overlap, complete costs or documented missing/failure. If impossible, narrow claim to simulation and report limitation. Confirmatory effect threshold not yet fixed; no award forecast.
