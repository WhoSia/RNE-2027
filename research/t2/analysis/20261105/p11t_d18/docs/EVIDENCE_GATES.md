# 증거 성숙도 / 무엇을 아직 모르는가

| 층 | 현재 확인 가능한 증거 | 가장 어려운 병목 | 판정 |
|---|---|---|---|
| 수학/시간 인과성 | Q 독립 사건 반례, T 보존·CFL | 원본 P10 재현, Δt→0 수렴 정리 | PARTIAL |
| 공간적 링크 모델 | S 차로별 대기열, T 3셀 finite CTM | 종단 위치, 차량 추종, 합류·회전, 실제 queue | PARTIAL |
| 다수 이동주체 | R 합성 car/ped 점유 | 상충 지점, 우선권, 보행시간, 차량 위치 | INITIAL |
| 실측 데이터 | MARWIS 소스텍스트 재조회 5967 frame / 19 상수구간, 공식 진주 표본 탐색 | 원본 SHA, 독립 관측단위, 현시-궤적 정렬 | BLOCKED |
| 독립 모델 | SUMO 공식 비교 가능성 확인 | 실제 동일조건 SUMO 실행 없음 | NOT EXECUTED |
| 정책 | P12 A/B 역사적 코드/결정 보존 | 모델 편향이 정책 순위를 뒤집는지 검증 전 | FROZEN |
| 전람회 | 현상과 구성 요소 정의, 학생 입상사례 비교 | 실제 계측, 설명 가능한 장치/프로토콜, 교차검증 | DRAFT |
| 논문 | 시간적/공간적 인과성과 이산화 반례계열 | CTM/SUMO 대비 신규 정리·독립 재현 | DRAFT |

이 표의 상태는 **업로드·로컬 실행·이전 연구문서**에 대한 증거 인벤토리이며 학술지/전람회 공식 심사 판정이 아니다.

## 실패와 홀드 지점
- 원래 P10 엔진의 핵심 반례 재현 증거 없음.
- 새로운 T 모델은 개별 차량이 아닌 유체화된 차량 등가량이고, 횡단보도 충돌/신호최적화가 아예 없음.
- P 링크를 '회전 포켓'이라 부르더라도 회전 결정, 차로 분기, 포켓 길이의 다차로 효과를 구현한 것은 아님.
- 실험에서 U 전체가 포화하였다는 주장은 거짓(4대 등가에 정확히 도달하지 않음).
- 출구 재개방 시점과 시간격자에 따른 불연속·비선형 전달로 수치적 편향이 나타남.
