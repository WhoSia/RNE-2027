# 전람회 시연 · 다음 녹색은 누구에게?

[demo.html](demo.html)을 내려받아 브라우저에서 연다. 시연 장면은 지난 실험의 합성 도착열 8개이며 시작 화면에서 모두 같은 관측과 양립한다.

## 90초 시연

1. 84틱에 직진 먼저를 고른다. 관측만으로는 두 현시가 각각 이기는 도착열이 있어 최악 후회는 27이다.
2. 86–87틱과 88–89틱의 순서를 공개한다. 여전히 두 도착열이 가능하다. 좌회전 선행 비용에서 직진 선행 비용을 빼면 −27 또는 +9이다. 이제 좌회전 먼저를 고르면 최악 후회가 9다.
3. 84–85틱도 공개한다. 처음 사례에서는 좌회전 먼저가 유리하다. 다음 사례 버튼으로 다른 도착열도 확인한다.
4. 종료 시 잔류 1대의 비용을 120틱으로 바꾼다. 같은 도착열이라도 직진 먼저가 유리하다. 비교 기준을 사전에 정해야 하는 이유를 말한다.

| 잔류 비용 | 후회 없이 정할 때 최대 확인 횟수 | 8개 도착열에 같은 가중치를 둔 평균 |
| --- | ---: | ---: |
| 0틱 | 2 | 1.50 |
| 60틱 | 3 | 1.75 |
| 120틱 | 0 | 0 |

계산은 최악 질문 횟수를 먼저 최소화하고 그 안에서 같은 가중치 평균을 최소화한다. 질문은 정확한 미래 순서 공개를 가정한다. 실제 예측기는 아직 없으며, 관측의 비용 및 예측 오차는 이 표에 포함되지 않는다. 실제 대기열 판정과 교차로 운영 개선은 별도로 검증한다.

## 우회 가능성 비교

기본 벌점 60틱에서 ‘다른 사례로’를 한 번 누르고 세 순서를 모두 연다.
우회 불가일 때 비용차가 +176이라 직진 선행을 고른다. 같은 화면에서 바로
뒤 직진차의 우회를 허용하면 비용차가 −830으로 바뀌어 좌회전 선행을
고른다. 현실에서 안전한 틈이나 차선 제약을 실제로 관측해야 하는 이유다.

## 두 번째 도착열에서 우회 시점 비교

아래의 ‘우회 기회가 같은 횟수라도’에서 1을 고르면
앞쪽 −3(좌회전 선행)과 뒤쪽 +35(직진 선행)가 나온다.
6을 고르면 두 배치 모두 직진 선행이다.
작은 반전은 종료 벌점 60틱에서 나타났다.
[시점 실험과 현장 판독표](../bypass-windows/FINDINGS.md).

새 시드의 도착열로 바꾸면 한 번 조건에서 앞쪽 −113, 뒤쪽 +31이 나온다.
앞서 여섯 번에서 반전이 없었던 경우는 기존 시드의 대조로 유지한다.
별도 새 시드 패널에서는 여섯 번에서도 반전이 있었다.

## 추가 시연 · 센서가 틀리거나 늦으면?

기존 미래 도착 순서 공개 기능은 **결정 시점에 사용할 수 없는 완전정보 오라클**임을 분명히 말한다. 새 하단 패널은 별도의 두 합성 상황(좌회전 선행 비용 − 직진 선행 비용이 −113, +31)만 사용한다.

1. 첫 화면의 예측 오류 상한 10%, 측정 비용 0, 결정 전 보고 완료에서는 예측을 따른 결정의 최악 기대 후회 상한이 11.3이고, 정보 없는 고정안은 31이다.
2. 오류 상한을 30%로 바꾸면 예측을 무조건 따를 때의 상한이 33.9로 늘어 고정안 31로 돌아간다.
3. 오류 상한을 0%로 낮춰도 결과가 결정 뒤에 도착하도록 바꾸면 이번 현시에는 사용하지 못한다. 센서 정확도와 실제 정보 이용 가능성을 구별하기 위한 장면이다.
4. 다시 결정 전 보고로 바꾸고 센서 비용을 20으로 올리면 완벽한 예측이라도 계산상 이득은 11뿐이다.

이는 이진 예측기를 실제로 훈련했다는 뜻이 아니야. 두 세계 각각에 성립하는 오류율 가정, 고정된 두 현시안, 동일 비용 단위와 정해 둔 종료 평가에 한정된 **결정 기준 설명**이다. 복잡한 실제 교차로의 현시 전환 시간·보행 안전·실제 기회 변동은 아직 다루지 않는다.
