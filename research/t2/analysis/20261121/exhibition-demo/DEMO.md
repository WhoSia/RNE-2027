# 전람회 시연 · 다음 녹색은 누구에게?

[demo.html](demo.html)을 내려받아 브라우저에서 연다. 시연 장면은 지난 실험의 합성 도착열 8개이며 시작 화면에서 모두 같은 관측과 양립한다.

## 90초 시연

1. 84틱에 직진 먼저를 고른다. 관측만으로는 두 현시가 각각 이기는 도착열이 있어 최악 후회는 27이다.
2. 86–87틱과 88–89틱의 순서를 공개한다. 여전히 두 도착열이 가능하다. 좌회전 선행 비용에서 직진 선행 비용을 빼면 −27 또는 +9이다. 이제 좌회전 먼저를 고르면 최악 후회가 9다.
3. 84–85틱도 공개한다. 처음 사례에서는 좌회전 먼저가 유리하다. 다음 사례 버튼으로 다른 도착열도 확인한다.
4. 종료 시 잔류 1대의 비용을 120틱으로 바꾼다. 같은 도착열이라도 직진 먼저가 유리하다. 비교 기준을 사전에 정해야 하는 이유를 말한다.

| 잔류 비용 | 후회 없이 정할 때 최대 확인 횟수 | 8개 도착열에 같은 가중치를 둔 평균 |
| --- | ---: | ---: |
| 0틱 | 2 | 1.50 |
| 60틱 | 3 | 1.75 |
| 120틱 | 0 | 0 |

계산은 최악 질문 횟수를 먼저 최소화하고 그 안에서 같은 가중치 평균을 최소화한다. 질문은 정확한 미래 순서 공개를 가정한다. 실제 예측기는 아직 없으며, 관측의 비용 및 예측 오차는 이 표에 포함되지 않는다. 실제 대기열 판정과 교차로 운영 개선은 별도로 검증한다.
