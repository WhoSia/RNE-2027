# T2 P13 — Same-observation sign-identification audit, preregistration

2026-11-21. Follows T2 adversarial audit and arrival-clock Cohort B, NOT a retrospective reclassification of previously seen findings.

## Central problem
Comparing two worlds with ΔJ=+34 vs ΔJ=-178 is not enough to prove sensor insufficiency. If their decision-time observations differ, the signs can be distinguished by the available observation. A valid strict alias requires EXACT SAME six-count observation, OPPOSITE ΔJ signs beyond ε, a common fixed abstract action description, and proper provenance.

## Pre-fixed formal criteria
1. Each record has an immutable independent world ID, a true independent arrival-history group ID, a six-integer observed vector, a numeric ΔJ, a declared action label and a provenance claim. The independent group ID must not be replaced by a counter or repeated geometry row.
2. Let ε=5 invented model cost units for this screening tool only. Contradictory optimal actions are supported only when min ΔJ < -ε and max ΔJ > ε within exactly matching observed vector AND the same action contract.
3. Otherwise flag one-sided or near-tie uncertainty; never infer a necessary extra sensor from a common weak optimum.
4. Count independent arrival groups, not enumerated correlated geometry rows; report both.
5. Reject nonfinite measurements, bool as numeric input, missing provenance and incompatible actions.
6. Existing seed96 arrival clock +34/-178 case must be marked **NOT an observational alias** because the six-count observation differed, despite opposite signs.
7. Any alias in artificial records is an executable guard regression, not a discovered T2 physical witness.
