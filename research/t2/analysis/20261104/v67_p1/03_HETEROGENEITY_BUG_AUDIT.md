# T2 v6.7-P1 — Bug and physical-meaning audit

Initial mixed-fleet candidate introduced persistent leader/follower gap violations because previously global length/minimum-gap constants remained in some insertion and following calculations. The testbed now routes each vehicle class through IDM interaction, insertion, connector rear clearance, rectangle construction, and storage accounting. A more conservative within-step follower buffer was needed to avoid tiny (~0.02m) numerical gaps persisting across many ticks. These changes also change the all-car base engine relative to v6.6; DO NOT claim exact metric equivalence to older v6.6. The matched P1 experiments compare conditions **within the same corrected v6.7 engine**.

The experimental exclusive pedestrian phase originally allowed connector occupancy at WALK start because the side-phase remaining time was computed to the end of side green rather than the start of the carved-out P phase. The correction subtracts exclusive-P time and a conservative estimated connector clearance duration. All 48 final trials show no *sampled* connector/WALK overlap. Actual pedestrian trajectory/crosswalk geometry still absent.

Earlier exploratory mixed tests under an earlier version and other settings produced repeated stopline violations in some high-demand/short-storage cases. The final 48-factorial suite had zero monitored braking warnings, but these failures remain a separate adversarial test target; no universal safety promotion is justified. Retain full reproducibility packages and assumptions for independent audit.
