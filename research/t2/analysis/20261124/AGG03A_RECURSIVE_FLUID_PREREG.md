# AGG03A / MACRO05A — recursive fluid closure and offline static optimization
Prospective. Same abstract corridor and deterministic LCG as MACRO02B, 24 arrivals, L counts6/12/18, dense/platoon/sparse, P1/3 R1/3, 12 static schedules, common exact micro checkpoint before t16 g4/o0. Test seeds180..199 (720 worlds), no fitting. All schedules evaluated in micro and two recursive fluid closures from the same checkpoint counts, with future exogenous S/L arrivals supplied identically to both for offline scenario planning, never presented as real-time available. Fluid A uses movement fractions fS=qS/(qS+qL), fL=1-fS. Old-state flows x=min(qS,fS,1,R-r) if S green else 0; a=min(qL,fL,1,P-p), y=min(p,1) if L green, z=min(r,1) if downstream gate. Fluid B uses fS/fL demand but reduces S/L competition only via same fraction; instead alternative explicit movement queues (separate admission channels, x=min(qS,1,R-r), a=min(qL,1,P-p)). B is a structural optimistic comparator, not a same-topology exact model. Fractional mass and old eligibility, all stocks nonnegative and within P/R; arrivals at end. Float tolerance1e-8, 240 horizon, no forced clearing; report terminal stock, aggregate costs incl external q; microscopic oracle min J over 12, macro argmin evaluated on exact micro, compare fixed g4/o0 and trained fixed from 02B (P=1 => g3/o0, P=3 => g4/o0), report mean errors, absolute cost errors, regret, worst regret and paired results by clock; report tie lexicographic with 1e-8 tolerance. Compare macro order information loss without claiming field control or exact CTM implementation. 8640 unique schedules each model, 25920 arms.
