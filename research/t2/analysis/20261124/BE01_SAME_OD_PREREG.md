# BE01 — same-origin/destination congestion game (prospective)
Analytical side track, not new real-driver evidence. N in {8,12,24}; two alternative paths with positive integer affine per-user latency cA(n)=a+b*n, cB(N-n)=c+d*(N-n); a,c in {1,5}, b,d in {0,1,2}, excluding b=d=0; 96 parameter worlds. Every count n=0..N; system cost C=n*cA(n)+(N-n)*cB(N-n). Exact integer optimum. For eps in {0,1,3}, epsilon equilibrium iff no existing user can reduce personal latency by >eps by a unilateral switch using post-switch congestion. Enumerate equilibria and min/max system cost ratio. For every initial n, simulate asynchronous unit switch A->B first if eligible else B->A, and synchronous all eligible users switch together, fixed repeated-state termination; compare final equilibrium/cycle and mean cycle cost (separate from equilibrium PoA). Verify exact Rosenthal potential Phi=sum_{k=1}^n cA(k)+sum_{k=1}^{N-n}cB(k), strictly falls under each accepted sequential unilateral improvement. Report pooled cases by epsilon, counts of worse/better worst equilibrium costs as eps expands, witness of strict individual benefit with increased system cost; no proof of empirical behavior, no actual route recommendations, no calibrated game or claim of novelty. Held literature: Li Wang Nie Wardrop bounded rationality (2024 preprint), Roughgarden & Tardos selfish routing, Chotibut route to chaos.
