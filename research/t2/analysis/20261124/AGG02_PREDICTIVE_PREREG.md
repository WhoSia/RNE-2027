# AGG02 — predictive coarse-graining, prospective
Reuse AGG01 old-space model, same 24 vehicles, left6/12/18, three clocks, P1/3 R1/3, twelve static schedules, common pre-t16 g4/o0, horizon240. Train seeds0..59 except mod5=0; new test seeds160..179; 1728/720 worlds, 29376 arms. Eight-tick blocks post t16. Predict future block transfer X using only state at block start and known abstract schedule, never within-block realized quantities at test. Base context P,R,g,o, time-block index; count key adds q length,p,r; movement key adds qS,qL and head; train cell supported iff >=4 distinct seeds, fallback hierarchically movement->count->context (context guaranteed). Compute three train conditional means E[D],E[B],E[X] per tick. Compare context direct, count independence=8 E[D]E[B], count joint=8 E[X], movement joint=8 E[X]. The joint correction equals learned conditional covariance; no causal interpretation. Report block absolute and squared error and signed bias, active-at-start q nonempty stratum, seed-level paired absolute error differences (descriptive, no IID confidence claim). Also check aggregation bound per observed block and conservation. Report both all idle-inclusive and active stratum; no policy optimization or road deployment.
