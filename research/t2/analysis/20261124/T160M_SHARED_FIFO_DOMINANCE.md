# T160M — monotonicity under shared FIFO with independent exits
Motivation: MACRO02B fixed-policy comparisons 8376 lower, 17544 equal, 0 higher when same-tick downstream release is reusable. This is not P158's common receiver: left pocket exits separately, straight receiver exits independently, upstream S and L permissions mutually exclusive and exogenous. Proof for this precise topology, not a new universal traffic theorem.
Let A(t) be cumulative exogenous arrivals before tick t, fixed ordered tape w. Let U(t) be number removed from the shared upstream FIFO (prefix length), L(u),S(u) prefix counts, Y(t) left exits and Z(t) straight downstream exits. For feasible states, pocket occupancy L(U)-Y, receiver occupancy S(U)-Z. Initially common feasible U,Y,Z and same tape. Given binary straight gate gS(t), left gate gL(t), downstream service d(t), with gS*gL=0, all exogenous:
Y'=min(L(U),Y+gL); Z'=min(S(U),Z+d).
If U=A, U'=U. Otherwise head w[U+1] determines eligibility: L -> U'=U+1 iff L(U)-Y<P; S -> U'=U+1 iff gS=1 and S(U)<R+Z (old-space) or S(U)<R+Z' (reuse); otherwise U'=U. External arrivals at tick end. This is exactly old-stock eligibility and one upstream FIFO removal/tick, with separate L exit. Same-step left pocket exit is NOT reused; S only is. 
Order state componentwise (U,Y,Z). Compare two feasible states at same t and A with U1<=U2,Y1<=Y2,Z1<=Z2. Y',Z' monotone because prefix counts monotone and min is monotone. If U1<U2, integer prefix increment <=1 implies U1'<=U1+1<=U2<=U2'. If U1=U2, same head, same arrival availability; eligibility monotone in Y,Z (reuse Z' also monotone). At equal input state reuse dominates old since Z'>=Z. By induction from common feasible state, (U,Y,Z)_reuse >= (U,Y,Z)_old at every tick. Integrated total outstanding after arrivals is A_after-Y'-Z'; hence J_reuse<=J_old for any common horizon. Movement-specific outstanding L(A_after)-Y' and S(A_after)-Z' separately weakly decrease as well. Proof works for fixed ordered tapes, arbitrary admissible common initial state consistent with cumulative counts, any fixed binary gates and service satisfying stated topology and one upstream removal/tick. Does not require independence of upstream movements. It breaks if receiver and sink are shared across movements, if admission priority depends on other movement stock, or if policies themselves change endogenously with state. No assertion of policy rank preservation: MACRO02B observed 10112 strict reversals of 142560 schedule pairs despite nonincreasing costs within every fixed schedule. Counterexample first seed0/left6/dense/P1/R1: (g3,o0) old537 reuse370, (g4,o0) old539 reuse332. Fixed-policy dominance and optimal-policy rank invariance are different propositions.
Hand proof; not Lean checked, not field-calibrated or novelty-certified. Daganzo 1994 conservation/finite storage and Gregoire et al. 2015 capacity-aware backpressure are established prior art; do not claim invention of these principles.
