# P148 — independent integer cell-transmission-inspired kernel
2026-11-24. Frozen before run.
Source method: Daganzo (1994), Cell Transmission Model, https://its.berkeley.edu/publications/cell-transmission-model-dynamic-representation-highway-traffic-consistent-hydrodynamic .
This is a deliberately reduced discrete two-cell conservation model, not full calibrated CTM, T2 reproduction or SUMO.
State (external backlog e, upstream u, receiving d, departed z). Capacities U,D. Each step adds integer arrivals a to external backlog, computes simultaneously entry min(e+a,U-u,2), transfer min(u,D-d,2)*green, exit min(d,sink,2), then updates stocks. No same-step reuse of freed storage. All units vehicles/tick; no physical time calibration.
Exhaustive invariant test U,D=1..6, e=0..3,u=0..U,d=0..D,a=0..2,sink=0..2,green=0..1. Assert nonnegative stocks, capacity and conservation, transfer=0 at red or downstream full, exit bounded. Independent C++ native kernel and JS oracle must agree on the entire integer trace digest (FNV-1a 64-bit over ASCII rows). Report exact state count.
Dynamic contrast: demand a=1 for ticks 0..23, then zero, U=6,D=1..6, upstream green iff (t+phi)%period<period/2, sink=2 if t%8<4 else 0. Period 4 or 8, phi=0..period-1, horizon 200. Cost sum external+upstream+downstream after tick, exact 24 vehicles clear, record denied-green ticks (u>0,d==D,green), not summed vehicle delays. Compare every cross-period phase pair within D; report reversal counts, not physical claims. Distinct implementation languages are independent numerical implementations of same model, not independent physical evidence. No policy transport to real roads.
