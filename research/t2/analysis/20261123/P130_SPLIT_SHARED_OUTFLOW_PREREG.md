Critical confounding: P129's movement-separated links each have an independent 2-second downstream exit headway, so P129 changed both route segregation and discharge bandwidth (plus travel time/storage). The fact separated topology still gives some local-denial/cost paradox has no pure isolation interpretation. 

**Fork new topology `movement_separate_shared_exit`:** per-movement L/S receiving links with **two cells each**, aggregate four receiving cells, but a SINGLE global 2-second downstream discharge clock. At each tick, if both links contain an eligible exit vehicle, fixed movement precedence S→L (document and test), allow at most one physical downstream exit. The upstream signals remain the same, and per-movement entrance cells are independent. This controls total storage cell count and exit frequency but *NOT* physical downstream traversal distance, link-specific allocation or precedence; cannot attribute differences purely to sharing.
