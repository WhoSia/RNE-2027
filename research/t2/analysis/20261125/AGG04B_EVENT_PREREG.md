# AGG04B — exact event aggregation of an abstract FIFO model
Prospective. Same discrete old-stock/old-space transition as AGG03A, no new control policy. From empty, N in {24,96,384}, seeds240..243, LCG shuffled equal S/L labels, exogenous arrivals every 1/4/12 abstract ticks, P=R=1 or 3, 12 previously fixed abstract schedules, horizon16*N+32. 72 worlds,864 schedules each in reference tick loop and event loop. Both terminate as soon as all N arrivals have exited. Reference uses same transition function, scans every tick. Event loop finds next tick with possible state change: arrival, head L with pocket room (always), head S with receiver room and S permission, pocket stock with L permission, receiver stock with sink permission. Compute next permitted phase from periodic calendar (no scanning long idle gaps), minimum across events; skip intervening ticks exactly, add skipped ticks times current stock (total and movement-specific), then execute identical tick. If no event before horizon, accumulate remainder and stop. Verify exact per-arm J,J_S,J_L, per-event state trace and event times, clearance, movement conservation/capacity. Report reference transition counts, event transition counts, skipped fraction by arrival stride and N; not runtime or memory claims. Event-search overhead not measured; shared kernel parity not independent physical validation. No actual road parameters, timing suggestions or sensing.
