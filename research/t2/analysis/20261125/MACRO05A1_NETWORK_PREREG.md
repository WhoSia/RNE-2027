# MACRO05A1 — normalized two-route spatial network, prospective
All quantities dimensionless, offline only. Same-origin/same-destination network: two common upstream cells U0,U1, two A cells, four B cells, two common downstream cells D0,D1. Each cell stores two commodity masses A/B as appropriate. dx=dt=1; S=min(n,2), R=min(2,(6-n)/2). Ordinary links advect each commodity proportional to its old stock. Old-state flows; simultaneous update. Diverge at U1: demands d_A=S(U1)*fraction_A, d_B=S(U1)*fraction_B. Strict FIFO gives shared scale min(1,R_A/d_A if d_A>0,R_B/d_B if d_B>0); relaxed movement-wise allocation sends min(d_i,R_i), no reallocation of unused share. Relaxed topology is a counterfactual service discipline, not equivalent lane geometry. Merge: branch sending caps min(S,last branch cap); allocate min(total demand,R_D0) proportionally to those demands; no independent receiving storage creation. External reservoir admission proportional to old commodity stocks, arrivals end tick. Sink service min(S(D1),cap); proportional commodity exit. Initial empty. 3 input profiles same total24: rate2 t0..11; rate2 t0..3,8..11,16..19; rate1 t0..23. Fixed A share .25/.5/.75; 3 exogenous A branch exit caps: constant2, .25 on [4,16), .5 on [8,24), otherwise2; 3 downstream sink capacities: constant2, 0 on [8,16), 1 on [0,24), otherwise2. 81 worlds x2 disciplines=162 arms, horizon128, stock integral end-step, all clearance tolerance1e-7. Verify per-step commodity mass, cell bounds and total diverge/merge constraints, no same-step forwarding. Record J total and per commodity, terminal stock, spillback/blocked-demand diagnostics, paired changes. Do not claim monotonicity theorem, real traffic efficacy, optimized physical control, or behavioral equilibrium. This is a finite counterfactual test of spatial model structural assumptions, not calibrated CTM or real-world signal design. Treiber & Kesting 2025 ch9/24 supports conceptual network construction.
