# T166 — exact event compression for a deterministic discrete conservation model
Let s_t be pre-tick stock and ordered queue state, a_t exogenous arrivals, and gamma_t the fixed periodic eligibility calendar. The original transition is s_(t+1)=F(s_t,a_t,gamma_t). Define next event u as the earliest tick >=t at which an arrival or any transition guard evaluated at the unchanged state s_t can be enabled. For j=t,...,u-1, a_j=0 and every transfer guard is false. Induction gives s_j=s_t and s_(j+1)=s_t throughout this interval. Thus the cumulative end-step stock cost is exactly (u-t)*N(s_t); the same identity holds for movement-specific counts. Apply the original transition at u. Induction across events gives identical states at event boundaries, identical nontrivial event trace, clearance time, and cost for a fixed input tape and calendar. Termination at a finite horizon is handled by integrating the final unchanged interval. This is a discrete-event simulation specialization, not a novel general theorem. Requires complete event guards, known next exogenous arrival in the offline simulator, and no hidden state evolution; not valid if acceleration, internal clocks, endogenous decisions or new physical dynamics change during skipped intervals unless those changes enter the event list. Computing next event costs time: fewer transitions alone does not prove speedup. AGG04B observed opposite timing signs across workload strata.
