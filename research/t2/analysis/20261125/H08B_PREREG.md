# H08B — dynamic decision sufficiency, preregistration
Parent: 451a320283df11452c872f852f4edc196f1e0d47. H08A found q and e=min(q,c) sufficient for three one-stage objectives in its restricted model; test whether this persists for multi-stage decisions. This is a synthetic finite control problem, not a calibrated traffic controller.
## Frozen model
Initial qS,qL in 0..3, downstream occupancies oS,oL in 0..2, storage K=2 each; 144 initial worlds equally weighted. Actions a=0,1,2 allocate two abstract service slots (a to S, 2-a to L); no physical signal actuation. q is an unbounded upstream queue, no rejection. Each stage has independent equiprobable arrival event (one S or one L) and downstream exit opportunity (one S or one L), independent across stages and initial states. Decision before event. Two event orderings: service then discharge then arrivals (SD); discharge then service then arrivals (DS). Actual transfer min(q, free space, slots). Discharge min(occupancy, exit opportunity); conservation exact. In DS, the exit opportunity is unknown at action choice; no new action within the stage. Current observed e=min(q,K-o) always defined before action/events. Model order known, not inferred.
Horizons h=1,2,3. Objectives separately known: cumulative upstream residual q after service and before arrival (total); max of cumulative S and L residuals (fairness, track cumulative sums); terminal total network mass after last arrival (equiv maximize network exits for fixed initial world, all arrivals admitted). No switching or clearance costs. No vehicle-order model.
Optimal first action from exact causal stochastic dynamic programming with full state (and cumulative sums if needed) available AFTER the first action and between stages; chance events not known until after each action. This is a first-decision information ablation with free subsequent state revelation, not a stationary partial observation policy. Compute integer expected costs scaled by 4^h; sum event branches, minimize only after realized stage. No oracle schedule. Compare total q, split q, current e, (q,e), (q,e,total o), (q,o) full. Within each information class, common optimizer for each objective separately, worlds in bad groups, uniform Bayes regret (best common deterministic action), worst-class deterministic minimax regret; retain first strict disjoint-optimal witness in q,e groups when present. Do not treat mean regret as physical delay.
## Falsification gates
H08B1: q,e may be insufficient beyond horizon 1; report both event orders and all objectives, null or positive. DS and terminal-mass are different one-stage objectives/model from H08A so no requirement to reproduce its sufficiency universally. H08B2: if q,e,total o restores exact optimality, report conditional effect; if not, retain witness. No posthoc threshold adjustment. Conservation/capacity assertions, direct native Python independent recursion vs JS integer aggregates if available. No novelty claim for generic MDP/aggregation/Bellman concepts. Follow-up only if it distinguishes physical mechanisms or observation-cost tradeoffs. K047 sealed; no RF, field actuation, Actions or new branch.
