# K047 독립 검토

1. ZIP을 풀고 `K047-review.html`을 브라우저에서 연다. 이동류를 자동 판정한 결과나 다른 검토자의 판정을 열기 전에 각자 같은 8개 화면을 본다.
2. 파란색 A는 앞차, 주황색 B는 뒤차다. A·B의 표본 시각과 신호 헤드 원시 상태를 함께 본다. 정지선과 출구의 위치를 지도로 확인한다. 관측이 끊겼거나 해당 신호의 적용 대상을 특정하기 어려우면 불명을 선택한다.
3. 항목을 선택하고 근거를 적는다. 불명인 경우에는 어떤 시각의 어떤 증거가 부족했는지 적는다. 화면을 바꾸기 전에 현재 구간을 저장한다.
4. 검토자 코드에 서로 다른 코드(예 A01·B01)를 입력하고 JSON을 내보낸다. 저장은 현재 브라우저 탭에 유지된다. 탭을 닫기 전에 JSON을 내보낸다.

차량은 관측된 중심·방향과 차체 치수로 그렸다. 주변 맥락은 0.1초 격자로 표시하며, 표시 시각과 실제 표본 시각은 최대 0.05초 차이 날 수 있다. 파일 끝에서 90초 추적 창이 잘릴 수 있다. 화면의 무검출은 해당 영역이 비어 있거나 통행 가능하다는 증거가 아니다. 대조 및 미확정 사례를 골라 만든 재점검 자료이며 모집단 정확도 평가 표본으로 사용하지 않는다.

자료는 Schicktanz et al., DLR Urban Traffic dataset v1.3.1의 K047 지도, 차량 궤적 및 신호 상태를 사용했다. 원래 객체 ID는 제거하고 검토 구간별 문자를 부여했다. https://doi.org/10.5281/zenodo.20919480
